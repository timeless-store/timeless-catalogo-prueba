# Timeless — catálogo web

Página de catálogo pública de Timeless Store. HTML + CSS + JS plano, sin build.

- El avance y los pendientes van en `PROGRESO.md`.
- Los productos se leen de `productos.csv` (o de la hoja publicada que se indique en `config.js`).
- **Este repositorio es público.** Aquí no se guarda nada interno del negocio: ni costos, ni márgenes, ni el documento de traspaso, ni enlaces a las hojas del dashboard.
- En cada cambio hay que subir el número de versión del caché en `service-worker.js`.
